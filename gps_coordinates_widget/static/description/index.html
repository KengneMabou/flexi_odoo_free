Gps coordinates widget

Module to get latitude and longitude from the browser as fields in a model

Overview

This module add the possibility to have coordinates (longitude and latitude) fields on any model that get their values automatically from the browser location api so that you can store them in database.

Installation

Simply add this module as dependency of your module in the manifest file.

Usage

To use the widget, simply add this widget (on xml view form) on some float fields on any model you would like to have gps coordinates. We suppose the fields that will cary our longitude and latitude coordinates are called 'my_field_latitude' and 'my_field_longitude' on our model: 
            <field name="my_field_latitude" widget="gps_coordinates" options="{'gps_type': 'latitude'}"/>

            <field name="my_field_longitude" widget="gps_coordinates" options="{'gps_type': 'longitude'}"/>
